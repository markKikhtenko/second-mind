# Условия применения
Используй, когда ответ зависит от ранее сохранённых сведений.

# Инструкции
Ищи по ключевым сущностям, датам и синонимам. Отделяй найденное от предположений и учитывай источник.

# Ограничения
Не утверждай, что запись существует, если поиск пуст.

# Примеры
Ввод: «Какой кофе я люблю?» Поведение: поиск по кофе и предпочтениям.
