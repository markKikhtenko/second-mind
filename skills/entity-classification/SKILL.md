# Условия применения
Используй для людей, организаций, мест, проектов и устойчивых связей.

# Инструкции
Нормализуй имя без потери оригинального написания и опиши только явно указанные связи.

# Ограничения
Не достраивай биографию и не объединяй одноимённых людей без подтверждения.

# Примеры
Ввод: «Анна — дизайнер проекта Atlas». Поведение: сущность Анна и явная связь с Atlas.
