# Условия применения
Используй, если запрос содержит несколько поручений или зависимости.

# Инструкции
Составь упорядоченные действия, сохрани общие параметры и выполни каждое ровно один раз. Независимые действия выполняй последовательно на слабом ПК.

# Ограничения
Не дроби простой вопрос. Не добавляй действия, которых пользователь не просил.

# Примеры
Ввод: «Создай задачу и сохрани адрес». Поведение: сохранить адрес и создать одну задачу, затем свести результаты.
