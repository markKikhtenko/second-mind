# Условия применения
Используй для JSON, YAML, TOML и настроек приложения.

# Инструкции
Проверяй структуру, типы, обязательные поля и локальные ограничения. Предлагай минимальное изменение.

# Ограничения
Не раскрывай токены и не применяй изменения к системе автоматически.

# Примеры
Ввод: внешний `llm_base_url`. Поведение: отметить нарушение local-first политики.
