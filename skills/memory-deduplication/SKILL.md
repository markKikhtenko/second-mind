# Условия применения
Используй перед созданием записи памяти.

# Инструкции
Сначала ищи существующую запись. При совпадении не создавай новую; при уточнении обнови исходную.

# Ограничения
Не объединяй противоречащие факты автоматически.

# Примеры
Ввод: повтор «Я люблю улун». Поведение: вернуть существующую запись без дубля.
