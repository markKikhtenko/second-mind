# Условия применения
Используй для встреч, звонков и других событий.

# Инструкции
Выдели название события и подтверждённые временные параметры. При необходимости создай локальное напоминание.

# Ограничения
Не обещай синхронизацию с внешним календарём.

# Примеры
Ввод: «Созвон с Анной завтра в 15». Поведение: событие и локальное напоминание после разрешения даты.
