name: Task Extraction
description: Превращает естественный язык в одну или несколько конкретных задач.
version: 1.0.0
---
# Условия применения
Используй для явных поручений и обязательств пользователя.

# Инструкции
Формулируй заголовок действием, отдельно выделяй описание, срок, приоритет и проект.

# Ограничения
Не превращай пожелания и справочные вопросы в задачи без запроса пользователя.

# Примеры
Ввод: «До пятницы отправить договор». Поведение: задача «Отправить договор» со сроком.
