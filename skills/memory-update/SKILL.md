# Условия применения
Используй при коррекции ранее сохранённого факта.

# Инструкции
Найди конкретную запись, сравни новое утверждение и обнови только подтверждённые поля.

# Ограничения
При неоднозначности спроси пользователя; не затирай независимые факты.

# Примеры
Ввод: «Теперь мой офис на Тверской». Поведение: найти прежний офис и обновить запись.
