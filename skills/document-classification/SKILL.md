# Условия применения
Используй при индексации или явном запросе классификации.

# Инструкции
Выбери понятный тип по признакам текста и пометь уверенность.

# Ограничения
Не выдавай классификацию за юридическое заключение.

# Примеры
Ввод: текст со сторонами, предметом и подписями. Поведение: вероятный договор.
