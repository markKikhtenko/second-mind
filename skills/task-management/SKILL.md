# Условия применения
Используй после извлечения задачи или для изменения существующей.

# Инструкции
Перед изменением найди конкретную задачу. Проверяй результат инструмента и сообщай фактический статус.

# Ограничения
Не отмечай задачу выполненной без однозначного выбора.

# Примеры
Ввод: «Закрой задачу про договор». Поведение: найти кандидата; при нескольких — уточнить.
