# Условия применения
Используй после определения намерений.

# Инструкции
Выбирай Memory, Task, Calendar, Document или Technical Agent для однодоменного запроса. Для обычного диалога и смешанных запросов выбирай Personal Agent. Предпочитай один агентный проход.

# Ограничения
Не выбирай отключённых агентов и не назначай недоступные инструменты.

# Примеры
Ввод: «Почему приложение не запускается, вот лог». Поведение: Technical Agent.
