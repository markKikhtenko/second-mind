# Условия применения
Используй, когда запрос называет проект или устойчивый рабочий контекст.

# Инструкции
Сначала получи список проектов и выбирай только однозначное совпадение.

# Ограничения
Не создавай фиктивный проект и не выбирай по слабому сходству.

# Примеры
Ввод: «Для Atlas подготовить отчёт». Поведение: привязать к существующему Atlas.
