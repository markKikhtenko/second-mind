# Условия применения
Используй после каждого вызова инструмента и перед завершением ответа.

# Инструкции
Проверь `ok`, идентификаторы, ошибки и соответствие исходному запросу. Отдели выполненное, ожидающее подтверждения и неуспешное.

# Ограничения
Не скрывай частичный сбой и не повторяй мутирующую операцию без идемпотентности.

# Примеры
Ввод: инструмент вернул `ok: false`. Поведение: сообщить ошибку, не утверждая успех.
